FinTeen — Gamified Financial Literacy for Teens

FinTeen is a personal project that I developed from concept to final execution, combining storytelling, visual design, animation, and interactive game development into a single experience.

I was responsible for the entire creative and visual production, including:

  • Concept Development — defining the visual direction, game concept, and overall experience.
  • Character Design — designing the characters and establishing their visual identity.
  • Storyboarding — planning scenes, interactions, and visual storytelling.
  • 3D Modeling & Materials — creating and preparing 3D assets, models, and materials.
  • Animation — bringing characters, assets, and scenes to life through animation.
  • UI & Graphic Design — designing the user interface, visual elements, and graphic assets.
  • Game Development & Integration — bringing the project together and implementing the interactive experience in Unity.

The project was created using Unity, Cinema 4D, Illustrator, and Photoshop, with the complete visual pipeline developed and executed by me.

From the initial concept and character design to modeling, materials, animation, UI, and final implementation, FinTeen was built as an end-to-end personal project to explore how visual storytelling and game design can create an engaging learning experience for younger audiences.

Concept. Design. Story. Animation. Development — created by me from start to finish.
